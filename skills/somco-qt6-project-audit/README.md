# somco-qt6-project-audit

A read-only audit skill for Qt6 projects that checks six dimensions in a single pass:

1. **Somco conventions** — house-style rules for QML, C++, and CMake (see `references/somco-conventions.md`)
2. **CMake quality** — structural and correctness checks for the build system
3. **Unit-test presence** — lightweight check for whether QML and C++ tests exist
4. **clang-tidy / clazy** — deterministic static analysis layer
5. **Code formatting** — clang-format and qmlformat dry-run checks
6. **qmllint** — QML type-checking and lint diagnostics

## Requirements

All external tools are **optional** — if a tool is not found, its checks are skipped with a warning and the audit continues with the remaining phases.

| Tool | Phase | If missing | Where to get it | Env var override |
|------|-------|------------|-----------------|------------------|
| `clang-tidy` | Static Analysis | Skipped with warning | Part of [LLVM](https://releases.llvm.org/download.html) | `CLANG_TIDY_PATH` |
| `clazy-standalone` | Static Analysis | Skipped with warning | [github.com/KDE/clazy](https://github.com/KDE/clazy) | `CLAZY_STANDALONE_PATH` |
| `compile_commands.json` | Static Analysis | clang-tidy + clazy both skipped | Generated by CMake (see below) | — |
| `clang-format` | Formatting | Skipped with warning | Part of [LLVM](https://releases.llvm.org/download.html) | `CLANG_FORMAT_PATH` |
| `qmlformat` | Formatting | Skipped with warning | Included with [Qt6 dev tools](https://www.qt.io/download) | `QMLFORMAT_PATH` |
| `qmllint` | QML Diagnostics | Skipped with warning | Included with [Qt6 dev tools](https://www.qt.io/download) | `QMLLINT_PATH` |

### Generating `compile_commands.json`

clang-tidy and clazy require a compilation database to understand your project. Generate it with CMake:

```bash
cmake -DCMAKE_EXPORT_COMPILE_COMMANDS=ON -B build
```

The skill searches for this file in the project root and common build directories (`build/`, `cmake-build-debug/`, etc.).

### Configuration files (auto-detected)

| File | Tool | If missing |
|------|------|------------|
| `.clang-format` | clang-format | Uses clang-format's built-in default style |
| `.clang-tidy` | clang-tidy | Uses clang-tidy's built-in default checks |
| `.qmlformat.ini` | qmlformat | Uses qmlformat's built-in default style |

## Usage

```
/somco-qt6-project-audit
```

Or ask your AI agent directly:

```
Audit this Qt6 project for quality
```

```
Run a Somco project audit on src/
```

## Output

- **Markdown report** — a combined report covering all six phases with a pass/fail verdict per dimension and an overall summary, printed directly in the conversation.
- **HTML report** — a standalone `.html` file generated from `references/template.html`, saved to the project directory. Can be opened in any browser for a formatted, shareable view of the audit results.

## Limitations

- This is static analysis only — it does not build or run your project.
- clang-tidy and clazy require a `compile_commands.json` to function; without it those phases are skipped entirely.
- qmllint diagnostics depend on your Qt6 installation's import paths being discoverable.
